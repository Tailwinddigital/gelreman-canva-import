# gelreman-canva-import

Doorgeefluik, geen archief.

Canva kan een design alleen importeren vanaf een openbare URL. Daarom staat hier
soms één HTML-bestand: een social-media post van [Gelreman](https://gelreman.nl)
die op weg is naar Canva. Zodra de import klaar is, wordt het bestand
weggehaald — meestal binnen een paar minuten.

Staat de repo leeg? Dan is er niets onderweg, en dat is de normale toestand.

Beeld en tekst zijn eigendom van Gelreman en de betrokken fotografen.
